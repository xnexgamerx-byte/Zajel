# ٢٨ — نموذج التاجر: حقول طلبه وحدها، كما في النظام المعتاد

> 2026-10-03 · طلبك مع صورة «إضافة طلبات» من النظام المعتاد: «اريد من التاجر بس هاي الامور»،
> و«الاساسي اسم ورقم وعنوان وسعر وعدد، هو مكتوب تلقائي 1».

---

## ١. الحقول

نموذج «شحنة جديدة» في بوابة التاجر صار بحقول الصورة، بترتيبٍ يُكتب به الطلب:

| | الحقل | |
|---|---|---|
| **الزبون** | اسم الزبون | **أساسي** — والمؤشّر فيه عند فتح الصفحة |
| | رقم الهاتف الأساسي | **أساسي** |
| | رقم الهاتف الثانوي | اختياري |
| **العنوان** | المحافظة · المنطقة | **أساسيّان** |
| | أقرب نقطة دالّة | اختياري |
| **الطلب** | السعر مع التوصيل | **أساسي** — ما يدفعه الزبون كاملاً، 0 إن دفع مسبقاً |
| | عدد القطع | **أساسي** — مكتوبٌ ١ تلقائياً |
| | نوع البضاعة | اختياري — «ملابس» مثلاً |
| | حجم الطلب | عادي أو كبير |
| | نوع الطلب | طلب جديد أو استبدال |
| | الملاحظات | اختياري — تُطبع على الوصل للمندوب |
| **رقم الوصل المطبوع** | («البروموكود» في النظام المعتاد) | اختياري — §٣ |

ثم **حفظ الشحنة**، فيعود النموذج فارغاً للطلب التالي، وفوقه بطاقةٌ خضراء برقم الشحنة واسم الزبون
والسعر، و«اطبع الوصل» و«اطلب استلاماً».

## ٢. ما شيل من نموذج التاجر

- **«من يدفع أجرة التوصيل؟»** ومربّع الأجرة: الأجرة على التاجر من تسعيرته مع الشركة، والسعر ما
  يدفعه الزبون كاملاً.
- **رقم الطلب عنده، الوزن، قابل للكسر، يُسمح بالفتح**: ليست في صورة النظام المعتاد. تبقى للموظّف
  في «تعديل الشحنة».
- ولا يُقبل منه أيٌّ منها ولو أُرسل بغير النموذج. وكان التاجر الذي «يُحاسَب مقدّماً» يستطيع أن
  يُسقط ذلك عن شحنته بإرسال «مقدّماً = لا» — أُغلق.

## ٣. رقم الوصل المطبوع («البروموكود»)

إن لصق التاجر على الطرد وصلاً من «وصولات للطباعة»، يمسح رمزه أو يكتب رقمه في هذا الحقل، فتحمل
الشحنة رقم الوصل: يجدها به المسح في المخزن والمندوب والبحث، ولا يحتاج طباعة وصلٍ آخر لها.

- يُقبل وصلٌ من دفاتره، أو من دفاتر «في المخزن» التي توزّعها الشركة.
- وصلٌ من دفتر تاجرٍ آخر يُردّ «ليس من وصولاتك المطبوعة» — بلا اسم ذلك التاجر.
- الوصل يُستعمل مرّةً: «استعملت هذا الوصل للشحنة …»، أو «استُعمل لشحنةٍ أخرى» إن كانت لغيره.
- الأرقام العربية والفراغات تُقرأ كما تُقرأ باللاتينية.

## ٤. حجم الطلب ونوعه يُريان

- **على الوصل:** وسم «استبدال» و«حجم كبير» بجانب «قابل للكسر».
- **عند المندوب:** في قائمة مهامّه، وفي صفحة الشحنة «استبدال — سلّم الجديد واستلم القديم من الزبون»،
  والحجم ونوع البضاعة.
- **عند الموظّف:** في صفحة الشحنة، وفي «خيارات إضافية» من نموذج الشحنة يُختاران ويُعدَّلان،
  وكل تعديلٍ في سجلّها.
- **في بوابة التاجر:** في صفحة الشحنة.
- الحجم لا يغيّر الأجرة، والاستبدال يُسعَّر كالتوصيل كما كان.

## ٥. و«إدخال سريع»

شيل منه «من يدفع الأجرة؟» كذلك: الأجرة على التاجر كما في نموذج الشحنة (docs/plan/27).

## ٦. التحديث على الخادم

```
cd /opt/zajel/deploy && sudo ./update.sh
```

ترحيلٌ واحد يجري وحده: عمود «حجم الطلب» في الشحنات، وكل شحنةٍ قائمة «عادي».
