# ٤٨ — خطة التطبيقات: تطبيق التاجر أوّلاً، بتصميم ملفك نفسه

> 2026-10-09 · بعد أن جرّبتَ الموقع واكتمل: «الان خلينا نمشي بخطة التطبيق — التصميم اريده مثل الصورة بالملف بالضبط».

| الجزء | الحالة |

| **تطبيق التاجر** — الرئيسية | ✅ كصورة ملفك: الأقسام والقياسات والألوان، بأرقام التاجر الحقيقية |

| **الأدوات السريعة** — طلبات الاستلام، طلباتي، الدعم، وقائمة «المزيد» | ✅ 2026-10-10 — docs/plan/56 |
| باقي شاشات التاجر | ⏳ المراحل التالية (§٤) |

### مطابقة التصميم
قِيست الصورة قياساً: موضع كل بطاقة وارتفاعها، وحجم كل نصّ من عرضه في الصورة، والألوان من نقاطها.
والفرق بين لقطة التطبيق والتصميم اليوم **نقطة إلى نقطتين** في أيّ قسم:

| القسم | التصميم (من أعلى الشاشة) | التطبيق |
|---|---|---|
| الإعلان | ٦٩ → ١٨٠ | ٧٠ → ١٧٩ |
| الرصيد | ١٨٧ → ٢٣٤ | ١٨٨ → ٢٣٣ |
| العدّادات الأربعة | ٢٤٠ → ٣٠٨ | ٢٤١ → ٣٠٧ |
| إنشاء شحنة | ٣١٤ → ٤٣٠ | ٣١٦ → ٤٢٨ |
| أدوات سريعة | ٤٤٠ → ٥٤٧ | ٤٤٢ → ٥٤٥ |
| للمعالجة / تحتاج انتباهك | ٥٥٤ → ٦٢٩ | ٥٥٦ → ٦٢٩ |
| آخر الشحنات | ٦٣٧ → ٧٥٢ | ٦٣٨ → ٧٥١ |
| الشريط السفلي | ٧٦١ → ٨١٥ | ٧٦١ → ٨١٥ |

الخطّ «القاهرة» نفسه خطّ الموقع، والأحمر **لون الشركة**: تطبيق شركةٍ لونها أخضر يأتي أخضر بالنسب نفسها.

### ما يختلف عن الصورة عن قصد
- **الأشرطة تحت العدّادات حقيقية**: نسبة كلّ عددٍ من الإجمالي، لا زينة. في الصورة تبدو متقاربة؛ عند تاجرٍ حقيقيّ تختلف.
- **صورة التاجر**: حرفُ اسمه بلون الشركة حتى نضيف رفع الصورة.
- **الإعلان أعلى الرئيسية**: صورة الإعلان التي في ملفك حتى ترفع الشركة إعلاناتها من «إعلانات التطبيق» في النظام — وعندها تنزلق إعلاناتها بنقاطها.

## ٢. كيف يعرف التطبيق شركته

```
config/zajel.json   { الاسم · عنوان النظام · اللون }
        │
        ▼
flutter build apk --dart-define-from-file=config/zajel.json
        │
        ▼
تطبيق «الزاجل»  ── يدخل التاجر ──▶  النظام يعيد: الاسم · اللون · الشعار
```

- **عنوان النظام هو الفرق الوحيد** بين تطبيق الزاجل وتطبيق البرق (docs/plan/13 §٦). لا اسم شركةٍ في الكود.
- الشركة تُعرف من عنوانها كالموقع تماماً (`zajel.wahaj.iq/api/v1/…`)، فتطبيق البرق لا يدخل بحساب الزاجل ولو تطابق الاسم.
- الرمز يُحفظ في خزنة الجهاز المشفّرة، ومدّته سنة، والخروج يُبطل رمز ذلك الجهاز وحده.
- حسابٌ يُوقف من النظام، أو تاجرٌ يُغلق عنه الدخول، **يخرج من التطبيق في طلبه التالي**.

## ٣. واجهة الربط

| الطلب | ما يعيده |
|---|---|
| `GET /api/v1/company` | اسم الشركة ولونها وشعارها — لشاشة الدخول |
| `POST /api/v1/login` | الرمز + اسم التاجر ومتجره + هوية الشركة |
| `GET /api/v1/me` | نفسه بلا رمز جديد |
| `POST /api/v1/logout` | يُبطل رمز هذا الجهاز |
| `GET /api/v1/merchant/shipments` | «شحناتي»: `filter` (all · open · delivered · processing · attention · returns) و`q` و`page`، مع عدد كل شريحة |
| `GET /api/v1/merchant/shipments/{id}` | الشحنة: مسارها، كود التسليم، سبب التعثّر، الزبون، الحساب، رابط التتبّع |
| `GET /merchant/shipments/form` · `/merchant/areas` · `/merchant/shipments/quote` · `POST /merchant/shipments` | «طلب جديد» (docs/plan/52) |
| `POST /merchant/shipments/read` · `POST /merchant/shipments/listen` | بالذكاء الاصطناعي وبالصوت (docs/plan/55) |
| `GET /merchant/processing` · `POST /merchant/processing/{id}` | «للمعالجة» (docs/plan/54) |
| `GET /merchant/finance` · `POST /merchant/finance/request` · `POST /merchant/finance/statements/{id}/confirm` | «المالية» (docs/plan/54) |
| `/merchant/pickups` · `/merchant/requests` · `/merchant/returns/{batch}/confirm` · `/merchant/support…` | الأدوات السريعة (docs/plan/56) |
| `GET /api/v1/merchant/home` | الرئيسية كلّها في طلبٍ واحد: التحيّة، الرصيد، العدّادات، للمعالجة، تحتاج انتباهك، الإعلانات، آخر الشحنات |

الأرقام من الحسابات نفسها التي تعرضها بوابة التاجر في الموقع — ما يراه في التطبيق هو ما يراه في الموقع.
و«آخر الشحنات» تقدّم ما ينتظر قراره (للمعالجة، المؤجّلة، الراجعة) على الأحدث.

## ٥. بعد التاجر

```
تطبيق التاجر (هذا) ──▶ تطبيق المندوب ──▶ خطّ البناء الآلي لكل شركة ──▶ تطبيق الكول سنتر
```

- **المندوب**: الواجهة نفسها جاهزة لدوره (`app: courier`)، وشاشاته تقابل تطبيق المندوب في الموقع.
- **خطّ البناء**: ملفّ إعداد لكل شركة وأيقونتها، وبناءٌ آليّ لأندرويد ثم iOS (docs/plan/13 §٢).
- **أندرويد أوّلاً** (٨٠٪ من هواتف العراق)، وiOS من الكود نفسه بلا إعادة كتابة.
