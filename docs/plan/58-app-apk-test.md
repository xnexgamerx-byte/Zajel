# ٥٨ — تجربة تطبيق التاجر على الهاتف

> 2026-10-10 · نسخة التنصيب (APK) تُبنى على أجهزة GitHub عند كلّ تغييرٍ في `apps/merchant` — سير العمل
> `.github/workflows/merchant-app.yml`: الفحص، والاختبارات، ثم نسختان.

## تنزيلها

1. في GitHub: المستودع ← **Actions** ← **Merchant app** ← آخر تشغيلٍ أخضر.
2. أسفل الصفحة في **Artifacts**:
   - **zajel-merchant-apk** — على النظام الحقيقي (`https://zajel.wahaj.iq`).
   - **demo-merchant-apk** — بيانات العرض، بلا نظام (لعرض الشكل على أحد).
3. يُنزَّل ملفّ zip، وفيه الـAPK. تبقى ١٤ يوماً.

## تنصيبها

- افتح الـAPK على الهاتف، واسمح بـ«التثبيت من مصادر غير معروفة» لمتصفّحك أو مدير الملفّات.
- **التوقيع توقيع التجربة**: كلّ بناءٍ جديد قد يرفض التحديث فوق القديم — احذف القديم ثم نصّب الجديد.
  ونسخة المتجر تُوقَّع بمفتاحٍ ثابت يُحفظ في أسرار المستودع، لا في الملفّات.

## قبل نسخة النظام الحقيقي

- حدّث الخادم أوّلاً، فطلبات التطبيق الجديدة عليه: `cd /opt/zajel/deploy && sudo ./update.sh`
- ادخل بحساب تاجرٍ تجريبي (لا بتاجرٍ حقيقيّ وبيانات زبائنه).
- «إنشاء بالذكاء الاصطناعي» و«بالتسجيل الصوتي» تحتاجان مفتاحيهما في `deploy/.env` على الخادم، والميزة
  مفعّلة للشركة من المنصّة.

## ما يُجرَّب على الهاتف خاصّة

| الشيء | كيف |
|---|---|
| **كاميرا المسح** | الزرّ الأوسط ← وصلٌ مطبوع من «وصلات للطباعة» ← يُقرأ الباركود ويُفتح «طلب جديد» عليه |
| **المايك** | «إنشاء بالتسجيل الصوتي» ← يسأل الإذن مرّة ← تكلّم ثم «أوقف» ← «سمعنا: …» |
| **الصور** | «إنشاء بالذكاء الاصطناعي» ← «لقطة شاشة» ← لقطة محادثةٍ تجريبية |
| **الملفّات** | «رفع شحنات من ملف» ← «نزّل القالب» ← عبّئه ← «اختر الملف» |
| **المتصفّح** | «وصلات للطباعة» ← «جهّز واطبع» ← تُفتح صفحة الطباعة ← اطبع أو احفظ PDF |
| **الاتصال وواتساب** | «للمعالجة» ← «اتّصل» و«واتساب»؛ و«الدعم» ← «واتساب الدعم» و«الشكاوى» |
