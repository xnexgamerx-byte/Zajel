## ⚠️ تصحيح مهم لتقييمي السابق

وصفتُ Mrasil سابقاً بأنه *"منصة شحن طرود خالصة"* استناداً إلى مساراته
(`create-shipment`, `shipments`, `returns`, `carriers`, `tracking`…).

**الفحص الدقيق أثبت أنها مسارات واجهة فقط. Mrasil تطبيق Next.js بلا خادم إطلاقاً.**

الدليل من كوده:
```
lib/config.ts →  BASE_URL = "https://www.marasil.sa/api"
                 BASE_URL = "http://localhost:8000/api"
```
- ملفات `app/api/*.ts` ليست نقاط خادم، بل **عملاء** لـ Redux Toolkit Query (`ordersApi.ts`, `shipmentApi.ts`, `profileApi.ts`) ينادون خادماً خارجياً
- **صفر** ORM (لا Prisma ولا Drizzle ولا Mongoose)
- **صفر** migration
- **صفر** جدول قاعدة بيانات
- **صفر** اختبار

### ما يعنيه هذا
منطق العمل كله — دورة حياة الشحنة، التسعير، تعيين المناديب، المرتجعات، الفوترة —
يعيش على خوادم `marasil.sa` الخاصة، **وليس في المستودع**.

> حتى لو أعطاك صاحبه الإذن غداً، **ستحصل على واجهة لنظام لا تملكه.**
> ستكتب الخادم كاملاً من الصفر، وهو 80% من العمل.

## كيف تُعرّب marketplace_platforms — الخطوات الفعلية

### ملف ١: `backend/database/seeders/CountrySeeder.php`
يحتوي حالياً **9 دول** بهذه البنية:
```php
'name_en' => 'Saudi Arabia',
'name_ar' => 'المملكة العربية السعودية',
'iso_code_2' => 'SA',
'currency_code' => 'SAR',
```
**عملك**: أضف صفاً واحداً للعراق:
```php
'name_en' => 'Iraq',
'name_ar' => 'العراق',
'iso_code_2' => 'IQ',
'currency_code' => 'IQD',
```

### ملف ٢: `backend/database/seeders/CitySeeder.php`
المدن مُجمَّعة حسب رمز الدولة، وكل مدينة بهذه البنية:
```php
'SA' => [
  ['name_en' => 'Riyadh', 'name_ar' => 'الرياض',
   'latitude' => '24.6877', 'longitude' => '46.7219',
   'cod_available' => true],
  ...
]
```
**عملك**: أضف كتلة `'IQ' => [ ... ]` فيها **١٨ محافظة** بإحداثياتها.

> 💎 **لاحظ `cod_available` لكل مدينة** — النظام يعرف أصلاً أن الدفع عند الاستلام
> متاح في مدن دون أخرى. هذا حقل جاهز لواقع العراق، ولم أجده في أي مشروع آخر.

### ملف ٣: ثلاث صفحات بليد
`portal/partials/hero.blade.php` · `portal/partials/how-it-works.blade.php` · `admin/travel/cities/index.blade.php`
نصوص تسويقية — استبدال مباشر.

### وبعدها: طبقة العراق الحقيقية (وهي عملك أنت لا نسخ)
- بوابات الدفع: زين كاش · آسيا حوالة · فاست باي · Qi · FIB
- العنونة بالعلامة المميزة بدل الرمز البريدي
- `+964` والتحقق عبر زين/آسياسيل/كورك

## ما يبقى جيداً في Mrasil رغم كل ذلك

لا تُهمله تماماً — بل استعمله في موضعه الصحيح: **مرجع واجهات**.

| ما يعطيك | القيمة |
|---|---|
| **168 مكوّن React** بواجهة عربية RTL ناضجة | أنماط جاهزة لشاشات الشحن |
| تدفّق **المرتجعات والاستبدالات** (4 مسارات) | أفضل معالجة عربية رأيتها لهذه المشكلة |
| `custom-tracking` — تتبع بعلامة التاجر | فكرة تُباع في الخطط الأعلى |
| `contracts` + `webhooks` | تصوّر واجهة منصة اشتراكات |

> **استعمله كمرجع بصري ووظيفي — لا كأساس تبني عليه.** وهو مجاني: النظر إلى الواجهة ودراسة تدفّقها لا يحتاج إذناً، لأن الأفكار والتدفقات غير محمية.
